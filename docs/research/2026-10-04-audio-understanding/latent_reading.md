Primary agent read methods/results via arXiv MCP. This is a research record, not a measured LightSem result. Exact downloaded-text hashes are in reading_manifest.json; metadata API 429s/timeouts left version fields incomplete.

| Paper | Read scope | Main decision-relevant observation |
|---|---|---|
| [Stem-JEPA 2408.02514](https://arxiv.org/abs/2408.02514) | MCP read_paper offsets 0–29500; method, data, retrieval/listening/alignment/downstream results | Missing-source latent prediction uses aligned patch targets and an EMA encoder. Its listening task intentionally emphasizes compatibility rather than timing. 160 ms temporal patches exist; original-data reproduction needs proprietary stems. |
| [Zero-shot retrieval 2411.19806](https://arxiv.org/abs/2411.19806) | MCP download text 0–40000, including the extended paper's methods and all experiments | Retrieval gains do not uniformly transfer to other tasks. Contrastive pretraining can encourage same-song retrieval of the wrong instrument. Drum-part confusion remains. A published conditioning change is useful precedent, not proof it will fix LightSem. |
| [MSCOL 2302.07077](https://arxiv.org/abs/2302.07077) | MCP read 0–12000; methods; official author repository | Explicitly time-shifted source/mixture positives and global pooling learn excerpt properties. A fine-event adaptation must change these choices rather than assume their invariance is desirable. [Author code/models](https://github.com/cgaroufis/MSCOL_SMC23); no separate reusable license verified. |
| [DisMix 2408.10807](https://arxiv.org/abs/2408.10807) | MCP 0–7000, 9000–19000, 33000–41500; web method/data corroboration | Query-conditioned source factors separate pitch and timbre, with pitch bottlenecks and reconstruction. Four-source synthetic chorales are a limited demonstration; no inference that arbitrary unknown instruments are discovered. |
| [COCOLA 2404.16969](https://arxiv.org/abs/2404.16969) | MCP 0–20000; all main methods/results, official repository | Aligned disjoint submixes form positives. Different windows from the same song can be negatives. Combined-corpus performance is much better than some individual-corpus models. Good reproducible coherence baseline; local timing/source detection needs separate targets. |
| [LOEV 2412.18955](https://arxiv.org/abs/2412.18955) | MCP 0–26000; main methods, experiments and conclusion | Preserving pitch/tempo-sensitive subspaces mitigates destructive invariance. Removing the harmful augmentation can still beat the intervention. Pan/source-time transformations were not demonstrated and remain our proposed extension. Code/checkpoint release not verified. |

Implementation choices proposed for LightSem: compare these objectives on a common small encoder; use genuine aligned performances for compatibility; train presence/absence independently; preserve a fast event path; measure consumed/native embeddings rather than only prediction projections. COCOLA is a useful initial reproduction because official code and checkpoint download instructions exist. Stem-JEPA is a clear objective-level reimplementation candidate, but the inspected repository does not establish publicly downloadable original weights. All code/checkpoint download links remain unexecuted.

Original Perplexity first-pass exclusion of Stem-JEPA is incorrect; second pass correctly included it. Raw answers also overstate causal attribution of old failures and sometimes confuse pooled interfaces or token counts with native temporal resolution. The main report and specialist notes supersede those raw synthesis statements.
