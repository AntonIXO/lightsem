# Beat-conditioned v3: результат 2026-09-09

Новая версия обучена; автоматическая проверка выявила оставшиеся проблемы. Прохождение отдельных метрик не считается общим успехом. Вкусовая оценка человеком не проводилась.

## Где был сбой

Предыдущая версия выдавала меняющиеся значения, но это не гарантировало видимого перемещения света. В ограниченном адаптере лучи сходились в небольшую область пола: детектор находил видимую смену геометрии лишь на 0,54% пар кадров Shpongle. Позднее расширение pan до ±180° не учитывало формулу направления луча в рендерере: 46,02% взвешенного света moving heads уходило вверх. Это диагноз тракта управления/видимости, а не доказательство, что удаление beat-признаков само по себе остановило модель.

Старые успешные метрики описывали распределение танцевальных дескрипторов и их слабую связь с аудио. Они не проверяли экранный результат. В Vibescience старый эксперимент закрыт с вычисленным `supports` для исходной узкой гипотезы и явной записью `product_accepted = 0`: пользователь отклонил видимое поведение. Старые gates не переписаны задним числом.

## Что изменилось

Вход снова содержит 92 канала на исходной сетке 40 Гц: 64 mel, 22 спектральных/огибающих признака, pulse clarity и пять beat-признаков. Модель: Conformer 3×192, A4 регрессия, B3 события, C17 совместный временной flow. В четверти обучающих последовательностей блок пяти clock-признаков заменяется TRAIN-средним; при обычном воспроизведении присутствует полный вход.

Движения переводятся в мировые целевые точки ниже фермы с разными опорными точками для шести приборов. Адаптер не генерирует временные эффекты. Неподвижные входные controls дают неподвижный свет. Для видимости на TRAIN-примерах фиксированы яркость/насыщенность/ширина лучей и haze 0,25; сравнение видео использует одинаковые параметры рендера.

Обучение: seed 0, 12,000 обновлений, batch 32, окна 640 кадров (16 с), 29.0 минут, NVIDIA GeForce RTX 5070, FP32. Использован последний запланированный checkpoint. Это один новый запуск, не сравнение нескольких обучений. TRAIN: 419 песен / 798 coaches; VAL: 40 канонических песен, заранее выбранные 60-секундные фрагменты. TEST не открывался.

## Самопроверка

Требуются независимые признаки: движение освещённых лучей; размах за две секунды; изменение положения света в видео с выключенными остальными ролями; отсутствие света вверх и высокочастотного дрожания. Скорость сама по себе не проходит тест: маленькое быстрое дрожание отвергается по размаху/HF. Яркость/проектор не заменяют движение прожекторов.

Чистый BPM-sweep проходит геометрию, но проваливает аудиоуправление при нулевой реакции на неритмический вход. Проверяется один и тот же шум генерации при подмене аудио, отдельная подмена шума и сохранение beat-признаков. Дополнительно до открытия результатов зарегистрированы подмены только 86 спектральных каналов при неизменных всех шести ритмических признаках, а также 10-секундный сдвиг спектральных признаков внутри трека.

| Зарегистрированная проверка | Результат |
|---|---|
| Избирательность событий вместо импульса на каждый beat | PASS |
| Целостность данных, checkpoint и GPU-исполнения | PASS |
| Соответствие движения правильному аудио | FAIL |
| Отсутствие избытка быстрого дрожания | PASS |
| Зависимость движения от аудио помимо beat | FAIL |
| Видимое движение лучей | PASS |

Доля физических/визуальных прошедших клипов: новая версия 1.000, предыдущая 0.000. Требовалось ≥0,75 у новой и улучшение ≥0,25. Контроль старых весов с одним исправленным адаптером: 1.000 физических/визуальных прошедших клипов; дополнительного обучения для него не было. Это отделяет вклад геометрического исправления от смены модели. Доля песен с достаточным неритмическим управлением: 0.025, требовалось ≥0,75.

Преимущество A по правильному аудио перед чужим при сохранённых beats: -0.2130, 95% CI [-0.5553, +0.0403], порог +0,05 и нижняя CI >0. Преимущество B по AP над beat-only: +0.0109, CI [+0.0010, +0.0219], порог +0,01 и нижняя CI >0.

Строгая проверка всех шести ритмических каналов: аудиоуправление на 0.025 песен. Локальное управление: 0.125; A-преимущество против сдвига внутри трека +0.0505, CI [-0.0318, +0.1287]. Дополнительные checks: `{"local_audio_alignment": false, "local_motion_control": false}`. Общий статус дополнительных проверок: **FAIL**.

## Shpongle

Полная длина 277.307 с, generation seed 101. Только аудио на входе, full-track context, flow 8 шагов, GPU-render 854×480/30 fps. Медианный размах лучей за 2 с: 22.93°, доля света вверх 0.00000. Детектор видимого движения head-only: 0.987. Реакция на удаление спектральных признаков при сохранённых rhythm-признаках 4.72°, на другой noise seed 16.78°.

## Предел вывода и воспроизведение

Это одна интегрированная версия: одновременно изменены входы, частота, головы модели, temporal flow и адаптер. Нельзя приписывать результат одному возврату beat-признаков. Контрфактические признаки — диагностические вмешательства, а не отдельные реальные аудиозаписи. Предпочтение по музыкальности/эстетике и перенос на новые жанры этими тестами не доказаны.

Все исходные gates/пороги, исходники, входы, initialization/final checkpoint и выводы сохранены с хешами. Основные модули: `beat_conditioned_model.py`, `beat_conditioned_render.py`, `quality_observer.py`, `beat_conditioned_metrics.py`. В каталоге `tooling` находятся `run_evaluation.py` (prepare/infer/render/summarize), `run_demo.py` (infer/render/observe), `make_report.py`. GPU-этапы выполняются последовательно под lock. Проверки отказываются молча перезаписывать незавершённые результаты. Исходная версия кода для этого запуска находится в `source`; запуск обучения производился из неё.
