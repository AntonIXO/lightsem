# Blind A/B

Watch each pair with sound, on the same screen, at the same volume.
The two clips in a pair use the SAME music and are brightness-matched, so
brightness is not a valid reason to prefer one.

Answer for every pair:

1. Which one is ON THE MUSIC?
2. Which one looks like a LIGHTING ENGINEER did it?

Write L or R (or `equal`) and a confidence from 1 to 5 in `score_sheet.csv`.
Do not open `KEY.json` until the sheet is filled in.
