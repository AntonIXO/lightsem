# Prospective exploratory extension

Recorded before corpus predictions or new student fits. User explicitly selected
exploratory comparisons and Shpongle demos while the annotation tool is prepared.
This extension permits computation without the missing human-annotation gate;
it does not make that gate pass or replace independent truth with model outputs.

## Scope retained

Execute the methods and controls of all four original hypotheses. Preserve
PREREGISTRATION_V1.md and all four native proposed records. Use the same frozen
source families, baseline C, physical rig, representations, paired seeds and
6000-step training settings. Source identity, support, finite-value, leakage,
resource and reproducibility checks remain mandatory. No TEST access.

The assessment role stays historical/exposed. The Shpongle track remains a
personal demonstration. Its ratings cannot be used to choose a method and then
claim an unbiased scientific result on the same song.

## Permitted exploratory endpoints

H1: record native-frame TransNet edit intervals, original observer candidates,
vetoed candidates and their intersection; report rate/timing changes. Without
independent content events, F1/recall/AP remain unmeasured. Do not label vetoed
candidates false merely because TransNet classified an edit.

H2: propagate the same SAM2 union-person anchors with Cutie, compare the fixed
hold/box/shift controls, record color/mask temporal changes and failure cases.
Stateless SAM2 is an incumbent, not manual truth. Distances to it measure change,
not accuracy. Independent foreground IoU, background-removal error and true
background-color error remain unmeasured until annotation.

H3: after synthetic instrument and TRAIN representation-retention checks, permit
all seven original arms by three paired seeds even while human annotation is
pending. Keep the original observer main labels common to all arms: H1 has no
independent pass yet, so its conditional label veto is not enabled here. Keep
stateless SAM2 masks common to isolate representation. Score full controls on
the historical observer proxy with explicit proxy names, alongside native
representation/retention diagnostics. Never insert proxy AP into the new
independent-content-event diagnostic. All 21 fits and final6000 checkpoints stay
required for an aggregate; partial fits are not a selected winning subset.

H4: permit a separate exploratory oracle using the frozen incumbent SAM2
reference support until manual masks exist. Preserve the equal-information
global comparator, candidate palette restrictions, fixed trajectory, held-out
half-second scoring times, donor/permutation controls, and non-RGB/luma/fade
guards. Name its endpoint observer-regional distance. It tests output capacity
relative to a proxy source picture; it does not establish audio predictability,
true-background reconstruction, or human preference. Recompute the original
test against independently frozen manual support when available.

Original magnitude targets remain reported independently. A small miss may
proceed to exploratory display under the user's authorization. It remains a
miss and cannot unlock confirmation or automatic baseline replacement.

## Deliveries and executable freeze

Build the annotation workspace first and allow annotation to proceed without
showing model outputs. Require a stage-specific manifest with exact sources,
code, checkpoints, normalization, commands and support before each corpus stage.
This prose is not a substitute for that executable binding.

The requested Shpongle comparison set must include C and the matched trained
incumbent, genuinely retrained cut-only/mask-only candidates, the temporal-color
candidate, and clearly labeled fixture-capacity examples. Downstream cut/mask
and combined demonstration fits are additional engineering runs; freeze their
exact interventions and resource allowance prospectively before fitting. Do not
mislabel an unchanged C stream as the output of a new supervision method.

Every delivered video keeps the accepted compact1080p AV1/AAC128k settings,
identical audio and camera, and the saved motion. Publish RGB-only invariants
where applicable, duration/decode/audio audits, method provenance, and a rating
page. Oracle/reference inputs must remain visible in descriptions. Keep all
outcomes and failed gates in the report; no new baseline is selected by code.
