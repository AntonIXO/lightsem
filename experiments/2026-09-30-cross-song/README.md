# C на другой музыке

[Открыть два диагностических ролика](http://127.0.0.1:8770/). Каждый — 2 минуты, участок 1:00–3:00 исходной песни, 1080p30 AV1/AAC, около 20 МБ.

| Трек | Файл | Цвет в показанном отрывке |
|---|---|---|
| Vanilla Ace — Ladykiller (Original Mix) | [Видео](/root/lightsem/runs/cross_song_20260930_v1/01/01_baseline_C_1080p_av1.mp4) | 47 сигналов, 0 смен палитры |
| AURORA — Cure For Me | [Видео](/root/lightsem/runs/cross_song_20260930_v1/02/02_baseline_C_1080p_av1.mp4) | 5 сигналов, 1 смена палитры |

Проверка **до рендера** обнаружила залипание цвета у Ladykiller: 55 сигналов за 180 секунд анализа, но одна активная палитра с долей 100%. Сигналы события и реальные изменения палитры проверяются отдельно.

Движения не являются покадровыми копиями: RMS между песнями — 18,34°, при замене только часов ритма — 18,59°. После выравнивания по счёту долей RMS уменьшается до 4,09°. У C общая процедурная библиотека взмахов на 2/4/8 долей, медленно изменяемая сохранённым образцом тела. Музыка меняет ритм, фазу и размах; новые фигуры по содержанию песни не обучались.

Найденные темпы 118 и 116 уд/мин близки. Эта пара проверяет разные входы при близком темпе. Медианные скорости 48,64 и 48,17°/с также близки.

Для каждой песни заново рассчитаны первые 180 секунд аудиопризнаков, ритма, громкости, предсказаний C и DMX. Показ начинается с 60-й секунды, без перезапуска истории или сглаживания в точке показа. Общий образец тела намеренно фиксирован; команды Shpongle не переиспользовались.

Постоянное правило проверять вырождение, неактивные выходы и дубликаты записано в [AGENTS.md](../../AGENTS.md) и в проектном Vibescience. Модуль lightsem.experiments.output_diagnostics применяется до рендера; четыре теста проверяют известные отказы. Предупреждения сохранены, пороги и checkpoint не подбирались по результату.

Проверены исходные PCM-префиксы, движение, палитры, контроль часов ритма, 3600 декодированных кадров и равномерные PTS каждого ролика. Звук независимо сверён с AAC-кодированием правильного исходного отрывка. Бейзлайн C не изменён.
